# 拾词

按日历天安排正式复习，把当天不会和模糊的词收集起来单独加练。网页版无外部依赖，不需要安装 npm 包；另提供可独立离线使用的安卓 APK。

## 在电脑上运行

双击 `启动拾词.cmd`，保持窗口打开，在浏览器访问 http://localhost:4173 。也可以运行 `npm start`。

首次使用包含 20 个示例词。点击“体验 10 词练习”可以试用循环。导入自己的词库后，可以在“我的词库”停用示例词库。

## 安卓手机

把根目录的 **`拾词-安卓安装包.apk`** 传到手机，用文件管理器打开并安装。支持 Android 8.0 及以上；安装后电脑关机也能使用，可在手机粘贴或输入新词、导入文件、按天复习。详见 [安卓手机安装与使用](安卓手机安装与使用.md)。

安卓版打包全部界面资源，词库和进度保存在应用内；朗读使用手机 TextToSpeech，优先已安装的离线英文语音。APK 已完成编译、签名和内容检查，尚未连接真机验证。未来更新覆盖安装，保留同一应用 ID 和签名密钥；不要先卸载。构建方法见 [android/README.md](android/README.md)。

原来的手机浏览器方式仍可用：电脑和手机连接同一个 Wi-Fi，打开启动窗口中的 `http://电脑局域网IP:4173`。这种方式需要电脑运行；局域网 HTTP 不支持离线缓存。

电脑版、手机浏览器和安卓应用的数据各自保存，当前没有自动同步。“学习设置”里的完整 JSON 备份可以迁移词库和学习记录。CSV 只包含单词内容，不包含进度。服务器仅提供静态界面文件，词库内容保存在访问设备的 IndexedDB。

## 复习规则

- 新词按导入顺序学习；启用的多个词库按导入的总体先后顺序合并。默认每天新词数为启用词库总词数除以 20 向上取整，也可手动设置。
- 正式复习默认在首次学习后第 1、2、4、7、15、30 天进行；之后每 30 天继续。漏过的复习不会补出多个重复任务，下一次正式回答后安排未来最近的计划日期。
- 正式第一遍“不会”：0 分变 1 分，之后每次加 2，即 1、3、5……。“模糊”加 1。“认识”默认分数减半向下取整，也可选减 3，最低为 0。
- 每个词每个日历天最多计一次正式结果。当天重复练习不影响困难分数和日期。
- 第一遍就认识的词完成本轮；不会或模糊的词进入回忆轮。回忆轮认识的词进入中文选英文验证；仍不熟悉的词继续回忆。验证错误的词重新回忆和验证，直到通过。少于 4 个可用的不同释义选项时改用输入英文验证。
- 当天出现过不会或模糊的词始终保留在当天薄弱词列表，即使后来答对。全部薄弱词包括当前分数大于 0 或今天练习中遇到困难的词。
- 薄弱词按困难分数降序排列，同分按导入顺序排列。列表最多显示前 100 个；加练与导出覆盖全部筛选结果。
- 退出或刷新保留当前题目、已显示的答案及剩余队列。跨日继续旧队列按独立加练处理，新的正式到期任务仍保留。
- 时间按设备本地日历计算，建议设备保持正确日期和时区。同一设备请在一个标签页中学习，避免同时修改。

## 导入

支持粘贴文本、CSV、TSV、TXT，文件应使用 UTF-8。

```text
abandon v. 放弃；抛弃
acquire v. 获得；习得
adapt v. 适应；改编
```

表格可按“英文、词性、中文释义”三列复制；两列英文和中文也支持。多列或不同顺序用表头：英文、词性、中文释义、音标、例句、例句翻译、搭配、记忆方法、近义词、考试年份。

同一词库内重复英文忽略大小写和多余空格，跳过重复并保留原始学习记录。不同词库可以保留同一个词，分别学习。CSV 支持带引号的逗号、引号和多行字段。

## 检查

`npm test` 验证按天计分、复习日期、加练隔离、CSV 往返和十万条导入解析。

所有公开静态资源列在 `server.cjs` 白名单中，备份文件与测试源码不会通过服务暴露。没有账号、云同步或自动生成例句与音标；缺少的可选字段直接隐藏。

## 自动发音与记忆方法

- 自动发音默认开启，可以在学习设置中关闭。英文卡片首次出现时朗读一次；同一张英文卡片显示释义时不会重复朗读。进入下一张或下一轮时再次朗读。
- 中文选英文阶段隐藏答案时不朗读，并停止上一张尚未结束的语音。选择正确或错误后，都只朗读公布的正确英文。输入英文验证同样适用。
- “听发音 / 再听一次”仍可手动重复播放。离开练习、完成练习或切换到后台会停止声音；快速换词会取消上一条语音。优先使用设备的英文语音。声音受浏览器和设备支持限制，无法启动时卡片提示手动启用。
- 答案区显示记忆方法，避免题目阶段泄露中文。已整理 20 个示例词，以及 20 个常见构词词条；词根构词展示每部分的中文、合义解释、必要的拼写变化。样例词源拆解参考 [Online Etymology Dictionary](https://www.etymonline.com/)，每条可打开对应依据。记忆画面由本应用自行编写，标记为情境联想。
- 未收录的导入词不会按字母强行拆解：优先保留词库自带的记忆方法，否则结合中文释义（以及已有例句）提供联想练习。这是离线词条库和联想提示，尚未接入为任意生词生成具体故事的在线模型。
- 升级兼容已有词库、学习记录和旧版备份，旧设置自动补上发音默认值。
